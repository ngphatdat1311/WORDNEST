## ✨ Tính năng nổi bật

### 1. Studio Nghe Chép Chính Tả YouTube (Chuẩn DOL)
- **Tự động bóc phụ đề thông minh**: Dán bất kỳ đường dẫn video YouTube nào, hệ thống tự động bóc tách phụ đề và dịch nghĩa tiếng Việt tức thì mà không cần nhập thủ công.
- **Thư viện 18+ video chất lượng cao**: Tuyển chọn các bài nói kinh điển (TED Talks, Steve Jobs, MrBeast, Queen, Daily English...) được xử lý 100% câu thoại, chia từng phân đoạn nhỏ 35 câu giúp học tập không bị quá tải.
- **3 chế độ luyện chép**:
  - *Chạm từ (Word Tap)*: Ghép từ nhanh bằng 1 tay trên điện thoại / laptop.
  - *Điền khuyết (Fill-in-the-blank)*: Tập trung vào từ vựng then chốt, tự động che từ.
  - *Gõ toàn bộ (Full Dictation)*: Ô nhập nhiều dòng tự động giãn cách khi câu dài, không bao giờ bị tràn hay che mất chữ, đếm số từ thông minh ở thanh tiêu đề.
- **Tiện ích học tập chuyên sâu**:
  - Điều hướng lịch sử mượt mà: Hỗ trợ nút mũi tên Back/Forward của trình duyệt và thao tác vuốt 2 ngón trên trackpad (Mac / Windows).
  - Tự động dịch song ngữ chuẩn xác Việt – Anh khi chuyển câu.
  - Nút **Che sub video** chống nhìn trộm phụ đề có sẵn trên YouTube.
  - Chấm điểm phát âm **Shadowing AI** với phân tích phần trăm phát âm chuẩn.

### 2. Không Chiến Từ Vựng 2.0 (Air Combat Arena)
- Đấu trường không chiến nâng cấp độ phân giải cao (`1100 × 620px`).
- Phi thuyền và đạn laser mượt mà, từ vựng hiển thị to rõ kèm nghĩa tiếng Việt.
- Nút **Tạm dừng** tiện lợi (hoặc bấm phím `Esc`).
- Tùy chỉnh tốc độ bay (Chậm, Chuẩn, Nhanh) và phóng to đấu trường full màn hình.
- Cho phép chọn nguồn từ linh hoạt: Từ vựng đến hạn ôn SRS, từ chưa thuộc, hoặc chọn theo từng thư mục cá nhân.

### 3. Hệ thống Lặp lại Ngắt quãng (SM-2 Spaced Repetition System)
- Thuật toán khoa học SuperMemo SM-2 tính toán ngày đến hạn ôn tập tối ưu.
- Flashcard lật mặt với phát âm Audio bản ngữ, Quiz trắc nghiệm 4 đáp án, và luyện viết từ vựng.
- Phân loại trạng thái: Đang học, Thành thạo, Khó nhớ.

### 4. Đồng bộ Đám mây & Đa nền tảng (Supabase Cloud Sync)
- Dữ liệu từ vựng, ghi chú và lịch sử học tập được đồng bộ 2 chiều tức thì giữa Desktop App và Điện thoại thông qua Supabase.
- Hỗ trợ xuất / nhập file dữ liệu sao lưu dự phòng an toàn.

## 🛠 Hướng dẫn phát triển & Chạy cục bộ

### Cài đặt môi trường
Yêu cầu Node.js >= 20.0.0:
```bash
git clone git@github.com:ngphatdat1311/WORDNEST.git
cd WORDNEST
npm install
```

### Chạy giao diện Web (Development)
```bash
npm run dev
```
Mở trình duyệt tại `http://localhost:3000`.

### Chạy Desktop App (Electron)
```bash
npm run build:electron
npm start
```

### Đóng gói bộ cài đặt Desktop (Production)
```bash
npm run dist
```
File cài đặt sẽ được tạo ra tại thư mục `dist/`.

## 🚀 Triển khai Web lên Vercel (Dùng chung 1 repo)

Nếu bạn muốn có thêm đường link Web online để học trên điện thoại hoặc chia sẻ bạn bè:
1. Đăng nhập [Vercel](https://vercel.com).
2. Chọn **Add New...** -> **Project**.
3. Chọn repo `WORDNEST` từ danh sách GitHub của bạn (Vercel hỗ trợ kết nối trực tiếp repo Private).
4. Giữ nguyên cấu hình mặc định (Next.js Framework Preset) và bấm **Deploy**.
5. Mỗi khi bạn `git push` lên nhánh `main` của repo `WORDNEST`, Vercel sẽ tự động cập nhật bản Web mới nhất!
